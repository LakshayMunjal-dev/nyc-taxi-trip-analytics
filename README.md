# NYC Taxi Trip Analytics

An end-to-end data analytics project analyzing NYC Yellow Taxi trip records using SQL and Power BI.

## Project Objective

Analyze NYC taxi trip data to identify:

- Hourly and daily demand patterns
- Revenue trends
- High-traffic pickup and drop-off zones
- Trip distance and fare relationships
- Payment method distributions
- Popular taxi routes

## Tech Stack

- SQL Server
- SQL
- Power BI
- NYC TLC Trip Record Data
- Git / GitHub
